# Mobile Technologies – Lab 2 – Marble Maze (starter)

Starter project for the lab. Gradle, all libraries, permissions and resources are ready –
you write the parts marked with `TODO Part N` (see the lab instruction).

## Getting started
1. Android Studio: **File → New → Project from Version Control**, paste the URL of this repository, **Clone**.
2. Run the app once – it starts, but almost nothing works yet.
3. Run the unit tests (`app/src/test/…` → right-click → **Run**). Some of them fail – your job is to make them pass.
4. **View → Tool Windows → TODO** lists every place you have to fill in.

## Git rules (local repository – nothing is pushed)
- Commit after every part: `Part 3: game loop`.
- Tag the checkpoints: `grade-3`, `grade-4`, `grade-5` (**Git → New Tag…**).
- Hand in a ZIP of the **whole project folder including the hidden `.git` folder** (run **Build → Clean Project** first).
